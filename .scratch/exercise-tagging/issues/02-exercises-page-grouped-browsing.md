# 02 — Grouped, searchable browsing on the Exercises page

**What to build:** The Exercises page shows exercises sectioned by Primary Muscle Group instead of one flat list, with a search box that narrows by exercise name only (not muscle group or type — that's what the sections are for). Strength, Stretch, and Mobility exercises for the same muscle group appear together in that group's section.

**Blocked by:** 01.

- [ ] The Exercises page groups exercises into sections by Primary Muscle Group, in a fixed, stable order (not alphabetical), rather than one flat list.
- [ ] A single search box filters by exercise name only; typing narrows the visible exercises within their sections.
- [ ] A muscle group section with no matching exercises (after search) doesn't show an empty/broken-looking section.
- [ ] When search matches nothing at all, a clear empty-state message is shown.
- [ ] Strength, Stretch, and Mobility exercises that share a Primary Muscle Group appear in the same section, not split apart by type.
- [ ] Existing create/edit/rename/delete actions on an exercise row continue to work unchanged.
